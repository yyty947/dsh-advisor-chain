# Second Opinion（第二意见）

在需要时向配置好的顾问模型征求第二意见。顾问是 DSH 原生的**只读子代理**：它能读文件、跑只读命令核实事实，但被限制在 read-only 沙箱内，改不了任何东西；回答只交给主模型，由主模型决定是否采纳。

## 它做什么

- **`second_opinion` 工具**：参数有 `question`（必填）、`context`（可选，仅放对话里看不到的信息：主模型的私有意图、没说出口的约束、被抄本省略的早期要点；大文件或长输出给路径即可，顾问会自己去读）、`mode`（继承 / 盲审）、`consult_id` + `follow_up`（追问）、`dual_opinions`（双意见）。
- **继承模式**：顾问收到当前会话（含当前轮次）的有界文本抄本——工具调用的名字和参数都保留，环境注入按来源标注，思考过程跳过；更早消息被省略时附最初请求的摘要。预算默认 120,000 字符，单条 4,000 字符。
- **盲审模式**：顾问不看对话，只依据问题与补充背景独立判断，可以推翻主代理的既有观点。
- **顾问模型链**：按顺序尝试；失败自动顺延到下一个。失败原因来自顾问子代理自己的请求错误（限流 / 鉴权 / 上下文超限 / 超时……），随结果真实显示；「完成但无正文」算失败。
- **超时**：到点时尚无回答正文 → 失败；已有正文 → 只要持续输出就不打断，停止 30 秒才中止；总时长兜底 `max(3 × 超时, 10 分钟)`。
- **追问**：`consult_id` 指向顾问子会话，重启后仍可追问；同一顾问、同模型同档位；最多 N 轮（默认 8）。
- **自动 / 手动触发**：auto 注入使用边界（重大方案前、高风险、低置信、连续受阻时主动咨询）；manual 仅用户明确要求时咨询。同一问题重复达到阈值时提示升级为强制咨询。
- **卡片**：父对话里以工具行显示——进行中「咨询中…」，完成后显示模型、尝试记录、截断标记与回答；顾问的审阅过程在子代理面板查看。

## 设置

设置 → Second Opinion：

| 配置 | 说明 |
|---|---|
| 启用开关 | 总开关 |
| 触发模式 | auto / manual |
| 默认咨询模式 | 继承 / 盲审（可被工具的 mode 参数按次覆盖） |
| 顾问模型链 | 有序列表：显示名、供应商、模型、推理档位、maxTokens、超时。供应商 / 模型 / 档位来自 DSH 的 设置 → 模型 页，这里只从中选择；每条显示可用状态，未授权的可一键「授权」 |
| 顾问提示词 | 整条链共用的回答要求 |
| 最多追问轮数 | 默认 8 |
| 限制 | 默认超时、抄本字符预算、单条消息上限、重复提问阈值 |

配置保存后即时生效（volatile 配置，无需重启）。

### 为什么要「授权」

DSH 默认只允许子代理使用与主对话相同的模型。顾问要跑在独立模型上，需要把该模型加入 DSH 的「子代理模型选择」白名单——设置页的「授权」按钮做的就是这件事（写入 DSH 自己的设置，可在 设置 → 插件 → 子代理 查看）。插件不会绕过这个白名单。

## 已验证的行为

- 顾问调用复用 DSH 已配置的 provider 路由与凭据，插件自身不保管 API Key。
- 顾问子会话被设为 read-only 沙箱；Windows 上的强制为「部分」级（网络不受约束），提示词同时要求只读，双保险。
- 推理档位按模型声明校验：模型未声明的档位在运行时忽略并注明，而不是让整个条目失败。
- 顾问身份不递归：顾问不能再派生子代理，也不能再调用 second_opinion。

## 从旧版本升级

0.3.9 及更早版本每次咨询都会向会话日志写入 `advisor/*` 事件；DSH 遇到不认识的事件类型会拒绝打开整个会话。本版本不再写入这类事件，并保留只读的兼容垫片：**只要本插件保持启用，含旧事件的会话照常打开；卸载本插件后它们可能无法打开。** 改写旧事件的修复工具计划在下一版本提供。完整说明见 [README 的升级须知](https://github.com/yyty947/dsh-advisor-chain#升级须知)。

## 已知限制

- 顾问看到的是文本化抄本而非原始多模态消息；图片与附件以占位符呈现，需要细节时由顾问用只读工具读取工作区中的文件。
- 追问复用同一顾问子会话：`maxTokens` 不随冷恢复保留；宿主会在父对话额外投递一条内容相同的子代理完成通知（工具说明已告知主模型忽略）。
- 与 dsh-advisor-group 同时启用时定位不同（本插件：只读顾问第二意见 + 上下文自动继承；advisor-group：多顾问接力会诊），工具名与提示段名已错开。
